# Migrate to domain.md 1.0.0-rc.2

Specification `1.0.0-rc.2` introduces the constitutional contract. Package and specification versions
remain independent; the unreleased package carrying this contract is `0.2.0`.

The vocabulary dependency is the IXO constitutional module merged at
`ixofoundation/ns@14df6d10d467712265216bfa6270dc6f59e0863b`:

- `https://w3id.org/ixo/vocab/v1/constitution#`
- `https://w3id.org/ixo/context/v1`

## Required migration

1. Change `version`, `conformance.spec_version`, and the schema URN to `1.0.0-rc.2`.
2. Add a unique, stable `id` to every `documents.entries[]` item. Keep document `role` unchanged.
3. Add a top-level `constitution` declaration whose `subject` exactly equals `domain.id`.
4. Use `status: not_applicable` only for a passive domain with no agents, agent controllers, bounded
   evaluation/execution, or executable governance. Supply a concrete reason.
5. Otherwise declare legal effect, norms, instruments, governance procedures, execution, and
   Constitutional-AI behavior. Each `instruments[].document_ref` must resolve to a document ID.
6. Add `Constitutional Governance` to required prose sections and add `constitution` to
   `validation.required_frontmatter` and `validation.review_required_for_changes_to`.
7. Run `domainmd lint` using the rc.2 package and resolve every constitutional rule code before adoption.

## Legal and operational effect

A de-novo constitution has operational effect by default. Do not set `legal_effect.status: verified`
unless both a jurisdiction IRI and resolvable authority evidence are present. The declaration does not
provide legal advice or itself prove that an instrument is adopted, current, or enforceable.

Constitutional-AI critique, revision, or policy evaluation constrains a proposal; it does not grant
identity, rights, capabilities, approval, or execution authority. Runtime consumers must independently
resolve current IID/controller state, protocol state, capability revocation, approvals, and enforcement
authority before acting.

## Executable governance

For `machine_executable` or `hybrid` execution, identify immutable implementations, conformance tests,
enforcement points, a fail-closed policy, and human-review gates. Audit records contain principle IDs,
outcomes, reason codes, evidence references, and execution receipts—not hidden model reasoning or
chain-of-thought.

Use `examples/project-authoring/domain.md` for a complete agentic package and
`examples/passive-dataset/domain.md` for the narrow passive exemption.
